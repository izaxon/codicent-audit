# Codicent Audit AI

Public website for Codicent Audit AI.

**Website:** https://audit.codicent.ai/

This repository contains only the approved static website. Customer audit data,
customer-specific requirements, operating configuration and private company material are not
published here.

The canonical website source is maintained privately in `codicent-core` and published to the
public `izaxon/codicent-audit` repository. Direct changes in the public repository may be
overwritten by a later approved release.
